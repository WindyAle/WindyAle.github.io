# Spotify 데이터 기반 곡 추천 플랫폼

> **음악 특성 분석으로 취향 저격**
> 25년간의 Spotify 데이터를 분석하여 사용자가 좋아할 곡을 찾아드립니다.

## 프로젝트 배경

음악 스트리밍 서비스에서 개인화된 추천은 사용자 경험의 핵심입니다. 이 프로젝트는 Spotify에서 제공하는 2000년부터 2025년까지의 곡 특성 데이터를 활용하여, 사용자가 입력한 곡과 음악적 특성이 유사한 곡들을 추천하는 플랫폼을 개발했습니다.

## 주요 기능

- 사용자가 입력한 곡의 음악적 특성(템포, 에너지, 댄스성 등) 분석
- KNN 알고리즘을 활용한 유사도 기반 곡 추천
- Streamlit 기반의 직관적인 웹 인터페이스

## 담당 역할

- **추천 알고리즘 구현**: KNN(K-Nearest Neighbors) 알고리즘을 활용하여 곡 간 유사도를 계산하고 추천 로직 구현
- **UI 개발**: Streamlit을 활용한 사용자 친화적인 웹 인터페이스 구현

## 기술 스택

| 분류 | 기술 |
|------|------|
| Language | Python |
| ML | Scikit-learn (KNN) |
| Data | Pandas, NumPy |
| UI | Streamlit |

## 팀 구성

- 4인 팀 프로젝트

## 프로젝트 회고

이론과 실습으로만 배운 모델을 실전에 가깝게 사용해 보고, 에러를 해결하면서 많은 새로운 공부가 되기도 했습니다. 특히 EDA 과정에서 학습용이 아닌 실제 데이터를 처리한다는 것이 얼마나 어렵고 신중을 요하는 작업인지를 느끼면서, 단순히 책으로 하는 공부보다는 직접 데이터를 다루어보는 경험이 더 많아져야겠다는 것을 절감했습니다.

ML 파트에서는 더 정확한 사용자 맞춤형 추천을 위해 어떻게 개선하는 것이 좋을지 고민하는 과정이 굉장히 귀중한 경험이 되었고, 또 평소 좋아하던 음악이라는 소재를 수치적으로 분석하는 과정이 매우 흥미로운 프로젝트였습니다.
